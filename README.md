## 🎯 What It Does

**PromptCraft** is an interactive developer workbench designed to test, benchmark, diff, and score AI prompt variants side-by-side across test scenarios.

Instead of testing prompts by copy-pasting back and forth in chat windows, PromptCraft provides:
1. **Dual Prompt Studio**: Write and tweak Prompt Variant A (Baseline) and Prompt Variant B (Structured Candidate) side-by-side with real-time token counters and `{{input}}` variable binding.
2. **Scenario Matrix**: Switch instantly between preloaded test cases (Customer Support Escalation, Code Review & Security Audit, Executive TL;DR Briefing) or inject custom payloads.
3. **Dual Execution Engine**: Runs both variants concurrently using zero-cost, high-fidelity offline simulation (so judges and reviewers can demo immediately with zero configuration) or live Google Gemini 1.5 Flash inference with your own API key.
4. **Visual Word-Level Diff**: Computes exact additions (green) and deletions (red) with unified and split view modes to observe how prompt instructions directly alter model outputs.
5. **Automated Quality Scorecard**: Scores responses across **Clarity**, **Conciseness**, and **Instruction Adherence**, automatically crowns the winning variant, and triggers celebratory feedback.
6. **One-Click Markdown Export**: Generates and copies clean benchmark reports ready for pull requests or documentation.

## 👥 Who It's For

- **AI Engineers & Prompt Designers**: Who need disciplined version comparison rather than ad-hoc chat guesses.
- **Developers Building with LLMs**: Who need to verify that adding constraints or few-shot examples doesn't cause regressions.
- **Hackathon Reviewers & Judges**: Looking for a functional, polished proof of concept that runs seamlessly without complex server setup or paid API dependencies.

## 🧠 What We Learned

1. **Spec-Driven Development Prevents Scope Creep**: Following the 6-stage Devpost Learn Skill Pack (`1-start`, `2-scope`, `3-prd`, `4-spec`, `5-build`, `6-ship`) forced us to clarify the unique kernel *before* writing any code. Having clear acceptance criteria allowed all 5 build slices to pass verification on the first attempt.
2. **Flipped Interaction Yields Better Software**: Engaging with the agent as an interviewer rather than a passive code generator surfaced critical edge cases early—such as the need for zero-config offline simulation so reviewers aren't blocked by API keys.
3. **Observability Matters in Prompt Engineering**: Treating prompts like unit-testable code with diff visualization and objective scoring criteria makes AI output iteration predictable and measurable.

## 🚀 Quick Start (Run Locally)

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone <your-repo-url>
cd buildai

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open **`http://localhost:5173/`** in your browser.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite 6, Tailwind CSS
- **Icons**: Lucide React
- **Diff Computation**: Custom client-side Longest Common Subsequence (LCS) word diff algorithm
- **Animations**: Canvas Confetti
- **Execution**: Dual-mode engine (offline simulation + optional live Google Gemini 1.5 Flash API)
