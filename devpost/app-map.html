Core System Data Flow

1. Inputs

Variant A & B Prompts + Test Scenario with {{input}}

2. Runner

Concurrent parallel execution via Simulation or Live Gemini API

3. Diff & Score

LCS token-diffing and multi-dimensional quality scoring

4. Review Deck

Side-by-side inspection, split diff, metrics & markdown export

Application Structure

User Interface Layer

  • • Header.jsx: Preset switcher, mode toggle, export action
  • • PromptEditor.jsx: Dual prompt panels & token counters
  • • ScenarioSelector.jsx: Test cases & custom input modal
  • • ResultsDeck.jsx: Multi-tab outputs, diff, and scorecard
  • • DiffViewer.jsx: Word-level additions/deletions visualizer
  • • Scorecard.jsx: Multi-dimensional metrics comparison
  • • SettingsModal.jsx: Gemini API key & simulation controls

Services & Logic Layer

  • • diffEngine.js: Fast Longest Common Subsequence (LCS)
  • • evaluator.js: Clarity, conciseness, adherence scoring
  • • runner.js: Dual async promise executor
  • • presets.js: Support, Code Review, and Leadership sets
